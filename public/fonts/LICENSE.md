# Fonts shipped with Cherry

All three families below are licensed under the SIL Open Font Licence 1.1,
which permits self-hosting and redistribution as part of this project. They are
served from Cherry's own origin so that no visitor request reaches a font CDN,
which is also what the `'self'`-only Content Security Policy requires.

| Family | Files | Used for | Licence | Source project |
| --- | --- | --- | --- | --- |
| EB Garamond | `eb-garamond-400.woff2`, `eb-garamond-500.woff2` | Display and headlines | SIL OFL 1.1 | github.com/octaviopardo/EBGaramond12 |
| Figtree | `figtree-400.woff2`, `figtree-500.woff2`, `figtree-600.woff2` | Interface and body text | SIL OFL 1.1 | github.com/erikdkennedy/figtree |
| IBM Plex Mono | `ibm-plex-mono-400.woff2` | Hashes, ids, timestamps and counts | SIL OFL 1.1 | github.com/IBM/plex |

The files are Latin-subset WOFF2 builds. Under OFL 1.1 the fonts may be bundled
and redistributed with this software, including for commercial use, provided
they are not sold on their own and the reserved font names are not applied to
modified versions. These files are unmodified.

The full licence text for each family is published by its source project at the
URL above.
