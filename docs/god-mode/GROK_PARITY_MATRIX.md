# Grok Bot parity matrix

Grok Bot is the factual benchmark. Every "documented behaviour" cell comes from `RESEARCH.md`
section H (docs.x.ai, accessed 2026-09-02). Every Cherry cell names the code path, test or capture
behind it and carries exactly one status: VALIDATED_REAL, SHIPPED_TESTED, EXPERIMENTAL, DESIGNED,
NOT_BUILT. Nothing here claims Grok Bot is obsolete.

| Capability | Grok Bot documented behaviour | Cherry current verified behaviour | Advantage or gap | Evidence | Cherry status |

| Persistent computer | One persistent cloud computer per account, shared by all Bots; work continues with the laptop closed | Local runner process on the user's machine; durable queue survives restart; nothing runs when the machine is off | Gap: no cloud computer.
